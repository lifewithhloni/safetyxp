# SafetyXP design system

## Goal
Create a reusable, maintainable visual foundation that preserves the current product experience while making future iteration easier.

## Foundations
- Color tokens for surface, text, primary action, success, warning, and neutral states
- Typography scale for headings, body, labels, and captions
- Spacing scale for layout and component rhythm
- Radius tokens for chips, cards, inputs, and modals
- Shadow tokens for elevation
- Motion tokens for transitions and entrance effects

## Reusable primitives
- Buttons
- Cards
- Inputs
- Sidebar navigation
- Badges and status pills
- Progress bars
- Theme-ready surfaces for light and dark mode

## Implementation guidance
- Centralize tokens in CSS variables.
- Compose UI primitives with token-based classes.
- Keep component props simple and consistent.
- Reuse the same primitives across pages and features.
